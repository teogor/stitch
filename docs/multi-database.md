# Multi-Database & Kotlin Multiplatform

Stitch is built to scale with your project, whether you're managing multiple Room databases or building for multiple platforms (Android, iOS, Desktop) using Kotlin Multiplatform (KMP).

---

## 🏗️ Multi-Database Support

Modern apps often use multiple databases for better data isolation. Stitch handles this complexity automatically by:
1.  **Unique DI Scoping**: Generating specific providers for each database to avoid injection conflicts.
2.  **Smart Package Naming**: Automatically creating unique package names for DI modules based on your project structure.

### Automatic unique-ing

If you have two databases in different packages:
- `com.app.core.AppDatabase`
- `com.app.user.UserDatabase`

Stitch will generate unique provider functions like `provideCoreAppDatabase` and `provideUserUserDatabase` in the `StitchModule`, ensuring that your dependency graph remains clear and error-free.

---

## 🌍 Kotlin Multiplatform (KMP)

Stitch is a first-class citizen in the KMP ecosystem. It fully supports the latest **Room3 (KMP Room)** features and automates the boilerplate required for multi-platform persistence.

### RoomDatabaseConstructor Generation

In Room3 KMP, you need to provide an `expect` object that implements `RoomDatabaseConstructor`. Stitch automates this for you!

```kotlin
// Automatically generated by Stitch for KMP support
@Suppress("KotlinNoActualForExpect")
expect object AppDatabaseConstructor : RoomDatabaseConstructor<AppDatabase> {
    override fun initialize(): AppDatabase
}
```

This eliminates the need for you to manually declare these objects for every database in your KMP project.

---

## ⚙️ Enabling KMP Support

To enable these features, simply set the `enableKmpSupport` flag in your module's `build.gradle.kts`:

```kotlin
stitch {
    enableKmpSupport = true
    generatedPackageName = "com.your.app.generated"
}
```

### Dependency Setup

Ensure you apply the Stitch KSP processor to your common and platform-specific source sets as described in the **[Installation Guide](releases/implementation.md)**.

## 🎯 Benefits for KMP Teams

- **Write Once, Generate Everywhere**: Define your DAOs in `commonMain`, and Stitch generates the platform-specific glue code for you.
- **Consistent API**: Your repositories look and behave the same across Android, iOS, and other targets.
- **Future-Proof**: Full support for Room3's multi-platform capabilities ensures your persistence layer is ready for the future of Kotlin development.
